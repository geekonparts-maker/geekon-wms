# GeekOn Product Photo Studio 📐

Εργαλείο για φωτογραφίες προϊόντων του eshop:

1. **Ανεβάζεις** τη φωτογραφία του προϊόντος.
2. **AI καθάρισμα (Nano Banana / Gemini):** λευκό φόντο, αφαίρεση υδατογραφήματος/θορύβου —
   χωρίς να αλλοιώνεται το ίδιο το προϊόν. Μπορείς να δίνεις και **extra εντολές**
   με ελεύθερο κείμενο (π.χ. «αφαίρεσε το καλώδιο»), με Αναίρεση/Επαναφορά.
3. **Διαστάσεις πάνω στο προϊόν:** βέλη, πλαίσιο Active Area, τίτλος και footer
   σχεδιάζονται **προγραμματιστικά** (όχι από το AI) — τα νούμερα είναι πάντα
   ακριβώς αυτά που πληκτρολόγησες και η εμφάνιση ενιαία σε όλο το eshop
   (πορτοκαλί GeekOn `#ED872D`, γραμματοσειρά Commissioner).
4. **Export** σε JPEG/PNG σε σταθερό τετράγωνο καμβά (default 1500×1500) με
   όνομα αρχείου από το SKU, προαιρετικά με το λογότυπο GeekOn στη γωνία.

## Εγκατάσταση

```bash
cd photo-studio
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # και βάλε μέσα το GEMINI_API_KEY σου
```

API key: από το [Google AI Studio](https://aistudio.google.com/apikey).
Για επαγγελματική χρήση ενεργοποίησε **billing** (το free tier έχει χαμηλά όρια
και τα δεδομένα μπορεί να χρησιμοποιηθούν για εκπαίδευση). Κόστος Nano Banana:
~$0.04 ανά παραγόμενη εικόνα. Το βήμα των διαστάσεων γίνεται τοπικά και είναι δωρεάν.

## Εκτέλεση

```bash
streamlit run app.py
```

Ανοίγει στον browser (default http://localhost:8501).

## Δομή

| Αρχείο | Ρόλος |
|---|---|
| `app.py` | Streamlit UI — ροή 3 βημάτων, presets, downloads |
| `annotator.py` | Μηχανή σχεδίασης διαστάσεων (Pillow): βέλη, πλαίσια, τυπογραφία |
| `gemini_client.py` | Κλήσεις στο Gemini image API με καθαρά μηνύματα σφάλματος |
| `fonts/` | Commissioner + IBM Plex Mono (τοπικά, με ελληνική υποστήριξη) |

## Σημειώσεις

- **Χωρίς σιωπηλές αποτυχίες:** αν το Gemini αρνηθεί ή αποτύχει, εμφανίζεται
  το μήνυμα του μοντέλου — δεν επιστρέφεται ποτέ «τελική» εικόνα που δεν καθαρίστηκε.
- **Υδατογραφήματα:** μόνο σε φωτογραφίες που έχεις δικαίωμα να χρησιμοποιήσεις
  (δικές σου ή υλικό προμηθευτή με άδεια).
- Το `.env` με το κλειδί **δεν** ανεβαίνει στο git (βλ. `.gitignore`).
